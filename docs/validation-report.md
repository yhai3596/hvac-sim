# 仿真验证报告

运行方式：`python3 -m sim.run_validation`（数据表自动生成到 `docs/validation-tables.md`，本报告为结果解读；重跑后请核对数值）。单元测试：`python3 -m sim.test_sim`（7 项全部通过）。

对比算法：
- **A 定频 on/off 基线**（北美被替代对象）
- **B 变频固定 Tes**（变频硬件、不学习）
- **C V1.44 复刻**（负荷预测 + Tes 自学习）

## 1. 主要结论

1. **模型行为合理**：循环次数 15~57 次/天、循环时长十几分钟到两小时、日耗电 9~50 kWh、显热 COP 2.3~3.3，均落在住宅分体机的合理范围；回差增大 → 循环变长变少、能力测量偏差 → Tes 学习方向性偏移等因果关系与机理预期一致。仿真平台可用于算法参数评估。
2. **V1.44 的节能收益得到复现**：典型夏周（S2）较定频基线 A 省电约 26%（30.6→22.8 kWh/天）、较固定 Tes 的 B 省电约 18%；循环次数从 35 次/天降至 24 次/天。轻负荷季（S3）较 B 仍省约 11% 且舒适度不受损。
3. **代价同样被复现——达温变慢、温度波动变大**：S2 中 V1.44 室温 RMSE 从 0.20℃ 升至 0.85℃、出带时间 0.3%→25.3%；设定阶跃场景（S4）中 pull-down 达温时间较基线慢约 32%（491→650 min）。这正是分析文档缺点 2.2-6（未区分 pull-down 与稳态循环）的定量体现。
4. **分析文档中定性指出的多个缺点，均可在平台上定量复现**（见第 3 节），为改进算法提供了可对照的基线。

## 2. 分场景解读

### S1 设计日稳态（恒定 35℃，预学习完成）

C 将循环从 23 次/天压到 6.7 次/天，省电 11%（对 B）。但平均 t2 达 125 min——远超 60 min 目标：机理是**"超时 TA+10min 延长"的尾段逻辑**。循环超过目标时间后，预测总能力随延长持续增大而目标总负荷冻结，比值最终越过 120% 触发能力 DOWN，把本已偏长的循环进一步拉长（正反馈），直到 240 min 无效判据兜底。这是 V1.44 规格书面语义的一个边界行为，建议列入改进清单（超时段应倾向 UP 或至少静默）。

### S2 典型夏周（冷启动学习）

7 天只学成 4 个（区间×昼夜）组合——外温 25~35℃ 横跨 4 个温度箱再乘昼夜分层，单箱样本积累慢，**冷启动期长的缺点（2.2-1）复现**。学成箱内 Tes 学到 14℃ 上限（夜间轻负荷），说明 Tes 上限本身可能约束节能上限，也说明在能力远大于负荷的工况下"拉长到 60 min"不可达，算法会持续贴边。

### S3 轻负荷季

循环天然变长（t1 平均 41 min），部分循环触发 t1≥120 min 丢样判据，学成箱数少——**缺点 2.2-8（轻负荷季学不到）复现**。C 节能 11% 且舒适度与基线持平，说明轻负荷是变 Te 的舒适-节能双赢区，恰恰是判据丢样最多的区间，改进价值明确。

### S4 设定阶跃（pull-down）

温控器设定从 25.5℃ 下调至 24.0℃ 后，A/B 达温 491 min，C 需 650 min（+32%），出带时间 46.7%。阶跃产生的长循环中尾段 DOWN 信号抬高 Tes、且长循环样本被丢弃无法修正负荷系数——**缺点 2.2-6 定量复现**。改进方向：识别 pull-down 事件（如 thermo-on 持续超阈值且未见周期性）时暂停 DOWN、临时满能力。

### S5 参数扫描

- **TA（目标运转时间）30→90 min**：日耗电 24.6→22.2 kWh（−10%），循环 28.7→23.7 次/天，但 RMSE 0.49→0.75℃、出带 16%→23%。TA 是节能-舒适的主权衡旋钮；当前默认 60 min 处在曲线中段，45 min 附近的折中值得在真机上评估。
- **温控器回差 0.5→2.0°F**（算法不可见）：循环次数 40→14.7 次/天，变化幅度远超算法自身参数的影响——**验证缺点 2.2-4：跨品牌温控器回差对循环统计的支配作用**。回差 0.5°F 时出带 27%（短循环+学习扰动），回差 2°F 时反而最稳。负荷系数学习读到的 t1/t2 由"负荷×回差"耦合决定，绝对阈值不可跨温控器迁移（与 CC 文档 5.2 的判断一致）。
- **能力测量偏差 ±15%**（模拟 Gr×Δh 误差）：−15%（低估自身能力）→ 算法多发 UP、偏向大能力，耗电 +6.5%、舒适更好；+15% → 反向。方向性影响清晰、幅度尚可控，但这是**在负荷系数同源偏移的自洽情形下**——若设备衰减导致测量与真实能力脱钩且负荷系数是健康期学下的，偏差会以差值形式直接进入能力规划（缺点 2.2-3），需要 CC 式健康门控。

## 3. 缺点复现对照表

| 分析文档缺点 | 复现场景 | 定量证据 |
| --- | --- | --- |
| 2.2-1 冷启动期长 | S2 | 7 天仅学成 4 个箱组合 |
| 2.2-3 能力测量偏差进入负荷标定 | S5c | ±15% 偏差 → 耗电 ±6.5%、Tes 方向性漂移 |
| 2.2-4 温控器回差支配 t1/t2 | S5b | 回差 0.5→2°F：循环 40→14.7 次/天 |
| 2.2-6 pull-down 被压慢 | S4 | 达温 +32%（491→650 min） |
| 2.2-8 长循环丢样 | S3 | 轻负荷季学成箱数少、t1 越限丢样 |
| 尾段延长的 DOWN 正反馈（新发现） | S1 | t2 均值 125 min，远超 60 min 目标 |

## 5. 平台使用说明

```bash
python3 -m sim.test_sim          # 单元测试
python3 -m sim.run_validation    # 全场景验证，重新生成数据表
```

自定义实验示例：

```python
from sim.scenarios import run_scenario
from sim.models import Weather

r = run_scenario("C", days=5.0, weather=Weather(t_mean=32, t_amp=6),
                 ta_min=45, deadband_f=1.5, meas_bias=0.05, prelearn_q=4000)
print(r.summary())
```

交互式可视化（浏览器内实时仿真、参数手调、动态曲线）见 `web/index.html`。

# LLM 方案分析示例报告

> 来源说明：本报告由 Claude 在开发会话中，基于仿真台「复制分析提示词」按钮导出的**真实提示词与真实运行数据**生成，用于验证提示词设计与报告形态（即"调用 Claude 自身能力测试"）。页面内「生成分析报告」按钮接入任一已配置 API 后即可产出同类报告。
>
> 输入数据：迈阿密夏季设计日 ×24h，方案1（基准）= V1.44/TA60/固定100%风量；方案2 = V1.44/TA30/自动风（60%/50min/+10%每10min）。

---

## 1. 执行摘要

方案2（自动风）以约 **10.7% 的节能**（61.0→54.5 kWh/天）和**决定性的除湿改善**（RH>60% 时间从 96% 降至 36%，RH 均值 64.4%→57.7%）优于基准，直接回应了"除湿不足"的客户反馈；代价是达温变慢（单次运转 t2 +49%，出带时间 32.2%→44.4%）。**但本组对比同时改变了 TA（60→30）与风量模式两个变量，达温变慢的归因不唯一，建议按单变量原则补做实验后再定参数。**方向上，湿区（迈阿密）机型应采用自动风并上调初始风量以换回达温性能。

## 2. 关键差异与机理解释

| 指标 | 方案1（基准） | 方案2 | 差异 | 机理 |
| --- | --- | --- | --- | --- |
| RH>60% 时间 | 96% | 36% | **−60pp** | 自动风低风量段（60%）盘管更冷 → SHR 显著下降 → 单位冷量的除湿占比大增；且循环从 27 次/天减至 11 次/天，停机后盘管存水再蒸发损失大幅减少 |
| kWh/天 | 61.0 | 54.5 | −10.7% | 循环减少 59% → 启动损失少；低风量段风机功率按风量三次方下降；长循环使 V1.44 能维持较低频率运行 |
| 达温 t2 | 36.5 min | 54.5 min | +49% | 低风量段显热能力下降（风量 60% ≈ 显热能力 −14%）→ 同样负荷需要更长运转；50 min 提档阈值意味着多数循环全程处于低风量 |
| 压缩机到峰值 | 7.5 min | 29.4 min | +292% | 低风量使 Te 偏低 → PI 控制压低频率，峰值频率来得更晚更缓——注意这是"出力节奏"变化而非爬升速率变化 |
| RMSE ℃ | 0.98 | 0.80 | −18% | 长循环、低出力运行使室温摆幅更小 |
| 出带 % | 32.2% | 44.4% | +38% | 与 RMSE 方向相反并不矛盾：偏差幅度变小（RMSE↓）但贴近设定带边缘缓慢逼近的时间变长（出带↑）——"慢而稳"的典型特征 |
| 除湿 L/天 | 121.3 | 99.7 | −18% | **反直觉但合理**：L/天是吞吐量，受室内湿度水平影响（基准室内更湿、渗透湿负荷驱动更强）；衡量舒适结果应看 RH 指标——方案2 的室内实际更干 |

## 3. 节能–达温–除湿三角权衡

- **节能与除湿在本例同向改善**（自动风同时贡献两者），代价集中在**达温**一侧：t2 +49%、出带 +38%。
- 迈阿密属 1A 湿热气候，RH>60% 时间 96%（基准）意味着几乎全天超出舒适湿度上限——除湿是该气候下的首要矛盾，方案2 的取舍方向正确。
- 需要警惕：出带 44.4% 偏高。参考仿真台 V9c 扫描，初始风量从 60% 提到 80% 可把出带压回 ~27%（优于固定 100% 风量的 32%），除湿仅小幅回吐——**三角中存在比方案2 更优的折中点**。

## 4. 推荐与参数建议

1. **采用自动风方向**（湿区机型默认），但**初始风量上调至 75~80%**、保持时长缩短至 30~40 min，兑换达温性能；
2. TA 建议维持 60 而非 30：本例循环时长主要由风量模式主导，TA30 未体现独立收益，反而在其他工况可能加剧短循环；
3. 制冷 Tes 上限建议按气候区收紧（湿区"湿度墙"），防止 V1.44 节能学习进一步侵蚀除湿。

## 5. 下一步实验建议

1. **单变量拆分**：补做「TA30+固定100%」与「TA60+自动风」两组，把 TA 与风量模式的贡献分离；
2. 自动风参数二维扫描：初始风量 {60,70,80}% × 保持时长 {30,40,50}min，以出带% 与 RH>60% 为双目标画折中前沿；
3. 换奥兰多/休斯顿复验（不同湿负荷水平下折中点是否漂移）；
4. 满足度 130% 情形下重跑（超配+自动风的短循环-除湿交互）；
5. 加入设定阶跃事件，验证自动风在 pull-down 场景是否需要"直接满风量"的旁路逻辑。
